### 阶段一：夯实底层基石（1-2个月）

*目标：满足“扎实的机器学习理论与编码能力”及“精通Python/C++”的要求。*

1. **数学与理论基础**
   * **重点**：概率论与数理统计（特别是贝叶斯推断、马尔可夫链）、线性代数、最优化理论（凸优化、梯度下降变体）。
   * **资源**：《Pattern Recognition and Machine Learning》(PRML)、《Deep Learning》(花书) 前几章。
2. **深度学习与Transformer架构**
   * **重点**：彻底吃透 Transformer（Self-Attention, Multi-head, Positional Encoding, LayerNorm/RMSNorm）。
   * **行动**：不要只看博客，**手写一个微型 Transformer**（支持前向和反向传播）。
   * **资源**：Andrej Karpathy 的 *Let's build GPT from scratch* 视频。
3. **工程与框架能力**
   * **重点**：精通 Python，熟悉 C++（用于底层算子优化）。熟练掌握 PyTorch。
   * **分布式基础**：了解 Data Parallelism (DDP) 和 Tensor/Pipeline Parallelism 的基本概念。

### 阶段二：大模型后训练核心技术（2-3个月）⭐ 核心重点

*目标：掌握 JD 中要求的“大语言模型：预训练、微调、对齐”及“强化学习：RLHF、奖励模型”。*

1. **监督微调（SFT）与参数高效微调（PEFT）**
   * **重点**：指令微调数据构造（Instruction Tuning）、LoRA/QLoRA 原理与实现、数据混合策略（Data Mixing）。
   * **实践**：使用 `LLaMA-Factory` 或 `Axolotl` 对开源模型（如 Llama-3, Qwen-2.5）进行 SFT。
2. **人类对齐与强化学习（RLHF & Beyond）**
   * **重点**：这是后训练的灵魂。深入理解 **PPO**（Proximal Policy Optimization）在 LLM 中的应用、**Reward Model (RM)** 的训练（Bradley-Terry 模型）。
   * **前沿算法**：必须掌握 **DPO** (Direct Preference Optimization)、**IPO**、**KTO**，以及目前大火的 **GRPO** (Group Relative Policy Optimization，DeepSeek-R1 的核心)。
   * **资源**：阅读原论文 (InstructGPT, DPO, DeepSeek-R1)，复现 HuggingFace 的 `trl` 库中的 RLHF 流程。
3. **多语言与跨文化对齐**
   * **针对 JD**：研究多语言 Tokenizer 的构建（如 SentencePiece, Tiktoken），少样本学习（Few-shot），以及跨文化价值观对齐（如不同国家的文化禁忌、语言习惯）。

### 阶段三：Agent 系统与复杂推理（1-2个月）⭐ 业务核心

*目标：满足“复杂推理与通用Agent系统构建”、“任务规划、工具使用、记忆机制”。*

1. **Agent 架构与规划（Planning）**
   * **重点**：ReAct, Plan-and-Solve, Reflexion 等范式。研究模型如何进行任务拆解（Task Decomposition）和反思（Self-Correction）。
2. **工具调用（Tool Learning / Function Calling）**
   * **重点**：让 LLM 准确输出 JSON 格式的 API 调用。研究如何微调模型以提高 Tool Calling 的准确率（如 Gorilla, Toolformer）。
3. **记忆机制与 RAG**
   * **重点**：短期记忆（Context Window 管理）、长期记忆（向量数据库如 Milvus/Faiss，检索增强生成 RAG）。
4. **复杂推理能力**
   * **重点**：Chain of Thought (CoT), Tree of Thoughts (ToT)。研究如何提升模型在数学、代码和逻辑推理上的表现。

### 阶段四：多模态与端到端语音技术（1-2个月）⭐ 差异化亮点

*目标：满足“多模态能力研究”、“端到端语音技术”、“多模态内容审核”。*

1. **视觉-语言模型（VLM）**
   * **重点**：理解 LLaVA 架构（Visual Encoder + Projector + LLM）。研究多模态对齐技术（如 BLIP-2, SigLIP, LLaVA-NeXT）。
2. **端到端语音大模型（Audio-LLM）**
   * **针对 JD**：这是目前极前沿的方向（如 Qwen-Audio, Mini-Omni, Llama-Omni）。研究如何将 Audio Encoder（如 Whisper, Wav2Vec）与 LLM 结合，实现语音到语音的端到端交互（绕过传统的 ASR->LLM->TTS 级联）。
3. **多模态内容审核**
   * **针对 JD**：研究如何利用 VLM 进行图文违规检测（涉黄、涉暴、政治敏感），了解多模态幻觉（Hallucination）在审核场景下的危害及缓解方法。

### 阶段五：工程化与推理加速（1个月）

*目标：满足“熟悉 vLLM、DeepSpeed”、“算法工程化经验”。*

1. **推理加速框架**
   * **重点**：深入理解 **vLLM** 的核心原理（PagedAttention, KV Cache 管理, Continuous Batching）。
   * **实践**：阅读 vLLM 源码，尝试部署并优化一个高并发的推理服务。
2. **分布式训练框架**
   * **重点**：熟练使用 **DeepSpeed** (ZeRO-1/2/3) 和 **Megatron-LM** 进行大模型训练。

### 阶段六：科研、开源与简历打造（贯穿始终）⭐ 拿 Offer 的关键

*目标：满足“顶会论文”、“知名开源贡献”、“竞赛获奖”等优先/加分项。*

1. **冲击顶会论文（ACL, EMNLP, NeurIPS, ICLR）**
   * **策略**：不要盲目做大模型预训练（算力不够）。**切入“后训练”的细分痛点**。
   * **选题建议**：
     * *多语言/跨文化*：低资源语言的 SFT 数据合成与对齐。
     * *Agent/推理*：提升 Agent 在复杂长文本环境下的工具调用成功率，或解决多步推理中的错误累积。
     * *RLHF/DPO*：改进 DPO 算法，解决其在多轮对话或特定垂直领域（如医疗、客服）中的性能退化问题。
2. **参与知名开源项目**
   * **行动**：去 GitHub 上给 **vLLM, LLaMA-Factory, HuggingFace TRL, XTuner** 等明星项目提 PR。哪怕只是修复 Bug、优化文档、或者添加一个小 Feature，在简历上也是极大的加分项。
3. **打造“业务闭环”思维**
   * JD 强调“已跑通 PMF 的国际化核心业务”。在面试时，不要只谈算法指标（如 Accuracy, BLEU），要谈**业务指标**（如：智能外呼的接通率、用户留存率、多模态审核的召回率与误伤率、API 调用的 Token 成本）。

### 阶段一：巩固客户端/移动端高阶架构基石（1-2个月）

*目标：满足“主导客户端整体架构设计与重构”、“3-5年客户端开发经验”的要求。*

1. **现代客户端架构模式与重构**
   * **重点**：深入掌握 MVVM、MVI（单向数据流）架构。精通组件化、模块化设计，掌握插件化架构以支持 Agent 能力的动态下发。
   * **行动**：复盘过往项目，总结如何进行“模块拆分”和“跨端协同”。
2. **高性能数据流与响应式编程**
   * **重点**：Agent 交互会产生大量异步数据流。必须精通 Kotlin Flow / RxJava / Combine，掌握复杂事件流的处理、背压（Backpressure）机制。
3. **跨端协同与底层性能优化**
   * **重点**：了解 Flutter 或字节内部跨端方案的底层渲染与通信机制（如 Platform Channel）。掌握内存泄漏排查、ANR/卡顿优化、启动速度优化，这是 OS 级架构师的底线。

### 阶段二：大模型与 Agent 工程化核心（2-3个月）⭐ 核心重点

*目标：满足“理解大模型原理”、“Agent开发经验”、“熟悉主流框架与生态”的要求。*

1. **大模型（LLM）的工程视角（非算法视角）**
   * **重点**：不需要手推反向传播，但必须懂 **Transformer 推理机制**（KV Cache、Attention 计算）。
   * **端侧部署**：研究模型量化（INT8/INT4/GPTQ/AWQ）、推理加速框架（**ONNX Runtime, CoreML, MNN, TFLite**），了解如何在移动端跑通 1B-3B 参数的小模型（如 Qwen2.5-1.5B, Phi-3）。
2. **主流 Agent 框架源码级剖析**
   * **重点**：JD 明确提到了 **Coze（扣子）、Spring AI Alibaba**。
   * **行动**：
     * 深入使用 Coze 搭建复杂工作流（Workflow），理解其节点编排、变量传递逻辑。
     * 学习 **LangChain / LlamaIndex** 的核心抽象（Chain, Agent, Tool, Memory）。
     * 阅读 **Spring AI** 源码，理解 Java/Spring 生态下如何优雅地集成 LLM 和 Function Calling。
3. **Agent 核心机制的工程实现**
   * **Function Calling / Tool Use**：掌握如何让 LLM 准确输出 JSON 格式的工具调用，并在端侧/后端安全地执行。
   * **RAG（检索增强生成）**：掌握向量数据库（Milvus, Faiss, 端侧 SQLite-vss）的集成，以及文档切片、Embedding 调优。
   * **Memory（记忆机制）**：设计短期记忆（Context Window 管理）和长期记忆（向量存储与检索）的端云同步方案。

### 阶段三：多 Agent 协同与端云 OS 级架构设计（2-3个月）⭐ 架构师核心

*目标：满足“设计和开发多Agent协同交互框架”、“高并发、低延迟”、“移动OS”场景要求。*

1. **多 Agent 协同架构（Multi-Agent System）**
   * **重点**：研究 AutoGen、CrewAI 等多智能体框架。设计 Agent 间的**通信协议**（如基于消息队列、事件总线或标准的 A2A 协议）。
   * **架构设计**：设计一个“主控 Agent（Router）” + “专业 Agent（如搜索、日程、代码）”的星型或网状拓扑结构，解决任务拆解与结果聚合。
2. **端云协同架构（Edge-Cloud Synergy）**
   * **针对“移动OS”**：这是该岗位的灵魂。云端跑大模型（重推理、复杂逻辑），端侧跑小模型（SLM，隐私数据、低延迟响应）。
   * **行动**：设计**智能路由策略（Router）**：根据任务复杂度、网络状态、隐私要求，动态决定请求是发给端侧模型还是云端模型。
3. **Agent 监控、调试与可观测性（Observability）**
   * **重点**：Agent 具有不确定性，调试极难。
   * **行动**：引入 **LangSmith / LangFuse / OpenTelemetry**，实现 Agent 调用链的 Trace（追踪）、Token 消耗监控、延迟分析、以及异常回滚机制。

### 阶段四：多模态融合与前沿探索（1-2个月）⭐ 差异化亮点

*目标：满足“多模态融合”、“跟踪前沿动态”、“加分项”要求。*

1. **多模态 Agent（Multimodal Agent）**
   * **重点**：将端侧感知（摄像头视觉流、麦克风音频流、屏幕截图）与 LLM 结合。
   * **场景**：设计类似“看着屏幕帮你操作手机”的视觉-语言-动作（VLA）Agent 架构。
2. **OS 级系统权限与 API 调度**
   * **重点**：Agent 要真正有用，必须能调用系统级 API（如读取通讯录、修改系统设置、跨 App 跳转）。研究 Android/iOS 的无障碍服务（Accessibility）、Intent/URL Scheme 以及沙盒权限管理。
3. **自主智能体演进（Agentic Workflow）**
   * **重点**：研究 ReAct、Plan-and-Solve、Reflexion 等范式，让 Agent 具备自我反思、自我纠错和自主规划能力。
