“AI 提示词工程师（Prompt Engineer）”在 2025–2026 年的自由职业市场中，已经从一个“只会写几句话”的入门岗位，演变成了一个​**结合了语言学、逻辑学、编程和业务理解的复合型技术岗位**​。

如果您想在这个领域接单或求职，需要具备以下核心技能矩阵：

### 1. 核心提示词工程技术 (Core Prompting Skills)

这是最基础也是最核心的能力，要求您知道如何“精准控制”大模型的输出。

* ​**高级提示词框架**​：熟练掌握并应用 Few-Shot（少样本提示）、Chain-of-Thought (CoT，思维链)、Tree of Thoughts (ToT，思维树)、ReAct（推理与行动）等高级技巧，引导模型进行复杂逻辑推理。
* ​**系统级设定 (System Prompting)**​：能够为 AI 设定极其严谨的“角色、语气、边界条件和输出格式（如严格的 JSON 格式）”，确保 AI 在企业级应用中不跑偏。
* ​**幻觉控制**​：懂得如何通过提示词技巧（如要求模型“只根据提供的上下文回答”、“如果不知道请回答未知”）来最大程度减少 AI 的“幻觉（胡说八道）”。

### 2. AI 模型原理与特性理解 (Model Knowledge)

不同的模型有不同的“脾气”，提示词工程师必须是“AI 驯兽师”。

* ​**模型差异认知**​：清楚 GPT-4o、Claude 3.5 Sonnet、Gemini 1.5 Pro 以及开源模型（如 Llama 3）各自的强项和弱项。例如，Claude 擅长长文本和代码，GPT 擅长通用逻辑和指令遵循。
* ​**参数调优**​：深刻理解 ​**Temperature（温度）**​、**Top-P** 等参数对输出创造性、随机性和确定性的影响，并能根据业务需求（如写诗 vs. 数据提取）进行精准调参。
* ​**多模态提示**​：除了文本，还需要掌握图像生成模型（如 Midjourney, Flux, Stable Diffusion）的视觉提示词编写，包括构图、光影、材质、镜头语言等专业词汇。

### 3. 编程与工程化能力 (Engineering & Coding) 💻 *高薪分水岭*

在 2026 年，纯靠“自然语言”写提示词已经不够了，企业需要的是能将提示词**工程化、自动化**的人才。

* ​**Python 基础**​：能够使用 Python 编写脚本，批量测试提示词的效果，或者调用 API 进行自动化处理。
* ​**API 与框架集成**​：熟悉 OpenAI / Anthropic 等 API 的调用。了解 ​**LangChain**​、**LlamaIndex** 等主流 AI 开发框架。
* ​**RAG（检索增强生成）设计**​：企业通常有自己的私有知识库。您需要懂得如何设计提示词，让 AI 结合外部向量数据库（如 Pinecone）中的文档来回答问题，而不是仅靠模型自带的记忆。
* ​**AI Agent（智能体）工作流设计**​：熟练使用 Coze、Dify、LangGraph 等平台，设计包含“工具调用（Tool Use/Function Calling）”的复杂 Agent 工作流。

### 4. 业务逻辑与领域知识 (Domain Expertise)

提示词工程师不能脱离业务，您必须能把“人类的商业需求”翻译成“AI 能懂的逻辑”。

* ​**需求拆解能力**​：客户说“我要一个能帮我写营销文案的 AI”，您需要将其拆解为：目标受众分析、痛点提取、文案结构生成、A/B 测试版本生成等多个步骤的 Prompt 链路。
* ​**行业 Know-How**​：如果您懂法律、医疗、金融或跨境电商，您就能写出极具专业深度的提示词（例如：让 AI 按照特定的法律条款审查合同），这比通用型提示词工程师更值钱。

### 5. 测试、评估与安全 (Testing, Evaluation & Security)

企业级应用要求 AI 输出必须稳定、安全。

* ​**红蓝对抗 (Red Teaming)**​：了解什么是“提示词注入攻击（Prompt Injection）”和“越狱（Jailbreak）”，并能在系统提示词中加入防御机制，防止用户套出 AI 的底层指令或生成违规内容。
* ​**自动化评估 (Eval)**​：懂得如何建立评估标准（如准确率、一致性、安全性），并使用自动化脚本对提示词进行成百上千次的回归测试，确保修改一个词不会导致其他功能崩溃。

如果您要在 Upwork 或 Fiverr 上接单，不要只写“我会写 Prompt”，而应该将服务​**产品化**​：

1. ​**AI 自动化工作流搭建**​：“为您搭建基于 RAG 的企业内部知识库问答系统（包含 Prompt 设计与 API 对接）”。
2. ​**特定岗位 AI 助手定制**​：“为您定制专属的 AI 法律顾问/医疗文献分析助手/跨境电商客服系统（提供完整的 System Prompt 和 Few-shot 示例）”。
3. ​**多模态视觉资产生成**​：“为品牌定制 Midjourney/Flux 视觉提示词库，确保生成图片符合品牌 VI 规范”。
4. ​**Prompt 审计与优化**​：“诊断您现有 AI 应用输出不稳定/幻觉严重的问题，提供 Prompt 优化方案及自动化测试脚本”。

**机器学习工程师（Machine Learning Engineer, MLE）** 是连接“数据科学”与“软件工程”的桥梁。他们的核心任务是将机器学习模型（尤其是当前火热的大语言模型）​**高效、稳定、低成本地部署到生产环境中**​。

在 2025–2026 年的技术语境下，MLE 的技能树已经发生了巨大的演变，从传统的经典机器学习全面向**大模型工程（LLM Engineering）** 和 **MLOps/LLMOps** 倾斜。

以下是成为一名高薪机器学习工程师所需的核心技能矩阵：

### 1. 编程语言与软件工程基础（基石）💻

MLE 首先必须是一个优秀的软件工程师，代码的健壮性和可扩展性至关重要。

* ​**Python 精通**​：不仅是写脚本，还要精通面向对象编程、异步编程（Asyncio）、多线程/多进程，以及性能优化（如使用 Cython 或 Numba 加速）。
* ​**系统设计与架构**​：懂得如何设计高并发、低延迟的 API 服务，理解微服务架构。
* ​**辅助语言**​：了解 **C++** 或 ​**Rust**​（在需要极致优化模型推理底层代码或编写自定义 CUDA 算子时非常吃香）。
* ​**版本控制与协作**​：熟练使用 Git，了解代码审查（Code Review）和敏捷开发流程。

### 2. 机器学习与深度学习核心（内功）🧠

* ​**经典机器学习**​：熟练掌握 Scikit-learn、XGBoost、LightGBM 等。理解回归、分类、聚类、降维等算法的数学原理及适用场景（在表格型数据业务中依然不可替代）。
* ​**深度学习框架**​：**PyTorch** 是目前的绝对主流（必须精通），了解 TensorFlow/JAX。能够从零手写 Transformer 架构、CNN、RNN 等网络结构。
* ​**数学基础**​：扎实的线性代数、微积分、概率论与最优化理论基础，这决定了您能否看懂最新的 AI 论文并复现它们。

### 3. 大模型与生成式 AI 工程（2026 年高薪关键）🚀

这是目前市场上需求最旺盛、薪资最高的细分方向。

* ​**模型微调（Fine-Tuning）**​：精通 PEFT（参数高效微调）技术，如 ​**LoRA、QLoRA、P-Tuning**​。懂得如何准备高质量数据集并使用 Hugging Face `transformers` 或 `trl` 库对开源模型（如 Llama 3, Qwen 2.5）进行指令微调。
* ​**RAG（检索增强生成）系统构建**​：不仅是调用 API，而是能自己搭建完整的 RAG 管道。包括文档解析（PDF/OCR）、文本分块（Chunking）策略、Embedding 模型选择、向量数据库（Pinecone, Milvus, Qdrant）调优，以及重排序（Reranking）技术。
* ​**推理优化与量化**​：懂得如何让大模型跑得更快、更省钱。掌握模型量化技术（如 GPTQ, AWQ, GGUF），熟练使用 **vLLM、TensorRT-LLM、ONNX Runtime** 等推理加速框架。
* ​**多模态处理**​：了解如何处理图像、音频与文本的联合输入（如 CLIP 架构、Vision Transformers）。

### 4. MLOps / LLMOps 与部署落地（工程化能力）🛠️

模型在笔记本上跑通只是第一步，MLE 的核心价值在于将其推向生产环境。

* ​**容器化与编排**​：精通 **Docker** 和 ​**Kubernetes (K8s)**​，能够将模型及其依赖环境打包并实现弹性扩缩容。
* ​**模型服务化（Model Serving）**​：熟练使用 FastAPI、Triton Inference Server、TorchServe 或 BentoML 将模型封装为高并发的 API。
* ​**CI/CD for ML (CT/CD)**​：搭建持续集成/持续部署管道，实现数据验证、模型训练、评估和部署的自动化。
* ​**模型监控与漂移检测**​：使用 Evidently AI、Prometheus、Grafana 等工具监控生产环境中的模型表现，检测数据漂移（Data Drift）和概念漂移。
* ​**云平台**​：熟悉 AWS (SageMaker)、GCP (Vertex AI) 或 Azure 的机器学习生态。

### 5. 数据处理与特征工程（燃料）📊

* ​**大数据处理**​：当数据量超出单机内存时，需要掌握 ​**PySpark**​、Dask 或 Ray 进行分布式数据处理。
* ​**数据库与 SQL**​：精通复杂 SQL 查询，能够从关系型数据库或数据仓库（如 Snowflake, BigQuery）中高效提取数据。
* ​**数据清洗与管道**​：熟练使用 Pandas、Polars（新一代高性能数据处理库），能够构建稳定、可复用的 ETL（提取、转换、加载）数据管道。

如果您打算以“机器学习工程师”的身份在自由职业市场（如 Upwork/Toptal）接单或求职，建议根据您的技能深度进行​**差异化定位**​：

1. ​**初级/通用 MLE（竞争激烈，需拼性价比）**​：
   * ​*服务*​：数据清洗、基础特征工程、使用现成 API 搭建简单的分类/回归模型、基础的 RAG 问答机器人搭建。
2. ​**高级 MLE / 架构师（需求大，时薪 \$100-\$250+）**​：
   * ​*服务*​：企业级 RAG 系统架构设计与优化（解决幻觉和检索不准问题）、开源大模型的私有化部署与微调（LoRA）、模型推理性能调优（降低 GPU 成本）。
3. ​**细分领域专家（极度稀缺，溢价极高）**​：
   * ​*服务*​：​**AI 音频/视频处理**​（如实时语音克隆、视频生成优化）、​**边缘 AI 部署**​（将模型压缩部署到手机或 IoT 设备上）、​**AI 安全与红蓝对抗**​（专门负责大模型的越狱防护和漏洞修复）。

​**总结**​： 如果说“提示词工程师”是教 AI 如何说话的​**老师**​，那么“机器学习工程师”就是为 AI 打造大脑、骨骼和神经系统的​**造物主**​。这个岗位门槛较高，需要持续学习最新的论文和工程框架，但其职业生命周期更长，且在 AI 时代的不可替代性极强。

“AI 视觉专家（AI Vision Expert / Computer Vision Engineer）”是人工智能领域中历史最悠久、但也正在经历最剧烈技术变革的岗位之一。

在 2025–2026 年的技术语境下，AI 视觉已经从传统的“识别与检测”（如人脸识别、车牌识别），全面跨越到了 ​**“多模态理解（VLM）”**​、**“生成式视觉（AIGC/3D）”** 以及 **“具身智能（Embodied AI）”** 时代。

如果您想在这个领域成为顶尖专家或高薪自由职业者，需要掌握以下核心技能矩阵：

### 1. 经典计算机视觉与深度学习（基石） 🧱

尽管大模型当道，但传统 CV 算法在工业界（如缺陷检测、自动驾驶）依然是绝对主力，因为它们的算力成本极低且确定性高。

* ​**核心任务算法**​：精通目标检测（**YOLO 系列** v8/v10/v11）、图像分割（​**Mask R-CNN, U-Net**​）、关键点检测、OCR（光学字符识别）。
* ​**基础框架与工具**​：精通 ​**PyTorch**​，熟练使用 **OpenCV** 进行图像预处理、视频流抽帧和基础几何变换。
* ​**经典网络架构**​：深刻理解 CNN（卷积神经网络）的演进（ResNet, EfficientNet, MobileNet），理解感受野、池化、注意力机制（CBAM, SE）的数学原理。

### 2. 视觉大模型与多模态理解（2026 年高薪关键） 🚀

这是目前企业需求最旺盛的方向，要求 AI 不仅能“看”，还能“理解”并与语言结合。

* ​**Vision Transformers (ViT)**​：彻底理解基于 Attention 机制的视觉模型架构，这是所有现代视觉大模型的底座。
* ​**基础视觉模型（Foundation Models）**​：精通 **SAM (Segment Anything Model)** 及其变体（SAM 2），掌握零样本/少样本的通用分割与特征提取。
* ​**多模态大模型（VLM）**​：熟悉 **CLIP** 架构，掌握 **LLaVA、Qwen-VL、InternVL** 等视觉语言模型的微调（LoRA）与推理。能够处理“图文对话”、“复杂图表推理”、“视频时序理解”等任务。

### 3. 生成式视觉与 3D 空间计算（当前最火热） 🎨

随着 Sora、Midjourney 以及空间计算（Apple Vision Pro）的爆发，3D 和生成式视觉人才极度稀缺。

* ​**图像/视频生成**​：深刻理解 **Diffusion Models（扩散模型）** 的数学原理（DDPM, DDIM），掌握 Stable Diffusion (SDXL, SD3)、ControlNet、AnimateDiff 的底层逻辑与微调（Dreambooth）。
* ​**3D 视觉与重建**​：掌握 **NeRF（神经辐射场）** 和目前最火的 ​**3D Gaussian Splatting (3DGS)**​。能够处理多视角图像并重建高质量的 3D 场景。
* ​**点云处理**​：熟练使用 ​**Open3D、PCL**​，掌握 3D 目标检测（如 PointPillars）和点云分割，这在自动驾驶和机器人导航中是刚需。

### 4. 模型部署与边缘计算（工程化落地能力） 💻

视觉模型通常算力消耗巨大，如何把庞大的模型塞进摄像头、手机或机器人里，是视觉专家的核心壁垒。

* ​**推理加速框架**​：精通 ​**TensorRT**​（NVIDIA 生态必备）、​**ONNX Runtime**​、OpenVINO。懂得如何通过算子融合、量化（INT8/FP16）将推理速度提升数倍。
* ​**边缘设备部署**​：熟悉 **NVIDIA Jetson** 系列、瑞芯微（Rockchip）、高通骁龙 NPU 的部署流程。掌握 **NCNN、MNN、TFLite** 等移动端推理框架。
* ​**底层优化（加分项）**​：了解 ​**CUDA 编程**​，能够手写或优化自定义的底层算子，解决特定硬件上的性能瓶颈。

### 5. 数据工程与特定领域 Know-How（行业壁垒） 📊

视觉任务极其依赖数据质量，且不同行业的“坑”完全不同。

* ​**数据管道**​：掌握大规模图像/视频的清洗、增强（Albumentations）、自动标注（利用 SAM 或大模型进行伪标签生成）流程。
* ​**行业应用经验**​：
  * ​*工业制造*​：懂光学成像原理、小样本缺陷检测、异常检测（Anomaly Detection）。
  * ​*自动驾驶*​：懂 BEV（鸟瞰图）感知、多传感器融合（Camera + LiDAR）、Occupancy Network。
  * ​*医疗影像*​：懂 DICOM 格式处理、3D 医学图像分割（如 nnU-Net）。

### 💡 自由职业 / 求职市场定位建议

如果您打算以“AI 视觉专家”的身份接单或求职，建议避开“通用图像分类”这种红海，选择以下​**高溢价细分赛道**​：

1. ​**工业视觉缺陷检测（AIOps）**​：
   * ​*服务*​：为制造业客户定制基于 YOLO 或异常检测算法的流水线质检系统。解决“正样本多、负样本（缺陷）极少”的数据不平衡痛点。
2. ​**多模态 AI Agent 视觉模块**​：
   * ​*服务*​：为自动化工作流（如 RPA、网页自动化）开发视觉识别模块，利用 VLM 或 SAM 让 AI 能够“看懂”复杂的 UI 界面并执行点击操作。
3. ​**3D 资产生成与数字人**​：
   * ​*服务*​：利用 3DGS 或 NeRF 技术，帮助电商客户将商品照片快速转化为可交互的 3D 模型；或基于视频驱动生成数字人（Audio2Face）。
4. ​**模型瘦身与端侧部署**​：
   * ​*服务*​：专门帮企业把跑在云端 A100 上的庞大视觉模型，通过量化和剪枝，压缩到可以运行在几百块钱的 ARM 开发板或手机 App 上。

​**总结**​： AI 视觉专家是一个 **“上限极高、极其硬核”** 的岗位。它要求您既要有推导数学公式的脑力，又要有手写 CUDA 优化算子的工程能力，还要对最新的生成式 AI 保持敏锐。在这个领域，**“能把模型部署到边缘设备上并稳定运行”** 的工程师，往往比“只会跑通开源代码”的算法研究员更受企业欢迎，薪资也更高。

"AI Agent 专家（AI Agent Engineer / Agentic AI Architect）"是 2025–2026 年 AI 行业中**最前沿、薪资天花板最高、且技术迭代最快**的岗位。

与"AI 自动化工作流"侧重于**预定义的线性流程**不同，AI Agent 的核心特征是 ​**"自主性"**​——Agent 能够根据模糊的高层目标，​**自行规划步骤、选择工具、处理异常、并在多轮交互中不断修正策略**​。

如果您想成为这个领域的顶尖专家，需要掌握以下核心技能矩阵：

### 1. Agent 核心架构与范式理解（理论基石） 🧠

您必须深刻理解 Agent 与传统 Chatbot 或 RPA 的本质区别。

* ​**Agent 循环（Agent Loop）**​：精通 **Perception → Planning → Action → Observation → Reflection** 的完整闭环。理解 ReAct（Reasoning + Acting）、Plan-and-Execute、Reflexion 等经典 Agent 范式的优劣。
* ​**规划与分解（Planning & Decomposition）**​：掌握如何让 LLM 将一个复杂目标（如"帮我做一份竞品分析报告"）拆解为多个可执行的子任务，并处理任务间的依赖关系。
* ​**自我纠错与反思（Self-Correction）**​：Agent 在执行失败后，能够分析错误原因并自动调整策略，而不是陷入死循环。

### 2. 主流 Agent 框架与编排工具（核心武器库） 🛠️

这是日常开发中最直接使用的工具，建议至少精通 2–3 个。

* ​**LangGraph（LangChain 生态）**​：目前最主流的 Agent 编排框架。基于**有向图（State Graph）** 构建 Agent 工作流，支持条件分支、循环、并行执行和人工介入（Human-in-the-loop）。是构建生产级 Agent 的首选。
* ​**CrewAI**​：专注于**多智能体协作（Multi-Agent）** 的框架。您可以定义不同角色的 Agent（如"研究员"、"写手"、"审核员"），让它们自主分工协作完成复杂任务。
* ​**AutoGen（微软）**​：另一个强大的多 Agent 对话框架，擅长让多个 Agent 通过对话协商来解决问题，特别适合代码生成和数据分析场景。
* ​**OpenAI Agents SDK / Anthropic MCP**​：掌握大模型厂商官方推出的 Agent 开发工具包，以及 **MCP（Model Context Protocol）** 这一新兴的 Agent 与外部工具/数据源标准化连接协议。
* ​**低代码 Agent 平台**​：熟悉 **Dify、Coze（扣子）、Flowise、Langflow** 等可视化 Agent 搭建平台，用于快速原型验证和交付给非技术客户。

### 3. 工具调用与 Function Calling（Agent 的"手和脚"） 🔧

Agent 的能力上限取决于它能调用多少外部工具。

* ​**Function Calling / Tool Use 机制**​：深刻理解 OpenAI、Anthropic、Google 等主流模型的 Tool Use API。能够精确定义工具的 JSON Schema（名称、描述、参数类型），让 LLM 准确判断何时调用哪个工具。
* ​**MCP（Model Context Protocol）服务器开发**​：2025–2026 年的新标准。能够开发 MCP Server，将数据库、文件系统、API、浏览器等外部资源以标准化方式暴露给 Agent。
* ​**代码执行沙箱**​：掌握如何安全地让 Agent 执行代码（如使用 ​**E2B、Docker 沙箱、Modal**​），实现数据分析、图表生成等动态任务。
* ​**浏览器自动化（Web Browsing）**​：熟悉 ​**Playwright、Puppeteer、Browserbase**​，让 Agent 能够自主浏览网页、填写表单、抓取数据。

### 4. 记忆与状态管理（Agent 的"大脑"） 💾

没有记忆的 Agent 只是一个高级 Chatbot。

* ​**短期记忆（Working Memory）**​：管理多轮对话的上下文窗口，掌握滑动窗口、摘要压缩（Summarization）等策略，避免 Token 超限。
* ​**长期记忆（Long-term Memory）**​：使用向量数据库（​**Pinecone、Qdrant、Weaviate、pgvector**​）存储用户画像、历史交互和知识片段，让 Agent 能够"记住"跨会话的信息。
* ​**状态图与检查点（State & Checkpointing）**​：在 LangGraph 等框架中，掌握如何持久化 Agent 的中间状态，实现断点续传、时间旅行调试（Time-travel Debugging）和人工审核节点。

### 5. 多智能体系统设计（Multi-Agent Orchestration） 🤝

复杂任务往往需要多个专业 Agent 协同完成。

* ​**架构模式**​：掌握 ​**Supervisor（主管模式）**​、​**Hierarchical（层级模式）**​、**Swarm（群体智能模式）** 等多 Agent 编排架构。
* ​**通信协议**​：理解 Agent 之间如何传递消息、共享状态、解决冲突。
* ​**角色设计**​：能够为不同 Agent 设计互补的角色、技能边界和权限控制（例如：一个 Agent 负责搜索，一个负责分析，一个负责撰写，一个负责审核）。

### 6. 大模型工程与推理优化（底层支撑） ⚙️

Agent 需要频繁调用 LLM，成本和延迟是生产环境的最大挑战。

* ​**模型路由与级联（Model Routing）**​：根据任务复杂度动态选择模型。简单任务用便宜的小模型（如 GPT-4o-mini），复杂推理用大模型（如 Claude Sonnet / o3），大幅降低成本。
* ​**结构化输出（Structured Output）**​：精通 **Pydantic、Instructor、Outlines** 等库，强制 LLM 输出符合预定义 Schema 的 JSON/对象，确保下游系统可靠解析。
* ​**Token 优化与成本控制**​：Agent 一次任务可能调用 LLM 数十次。您需要掌握 Prompt 压缩、缓存（Semantic Caching）、并行调用等策略。

### 7. 评估、测试与安全（生产级保障） 🛡️

Agent 的自主性意味着更高的失控风险，这是企业最担心的问题。

* ​**Agent 评估框架**​：掌握 **LangSmith、Braintrust、Arize Phoenix** 等工具，对 Agent 的任务完成率、工具调用准确率、推理步骤效率进行系统化评估。
* ​**沙箱与权限控制**​：严格限制 Agent 的操作边界（如：只能读取特定文件夹、只能发送经过人工审核的邮件），防止 Agent 执行危险操作。
* ​**防注入与对齐**​：防御 Prompt Injection 攻击，确保 Agent 不会被恶意用户诱导执行越权操作。
* ​**Human-in-the-loop（HITL）**​：在关键决策节点（如发送邮件、转账、删除数据）插入人工审批流程，平衡自动化效率与安全性。

### 8. 全栈工程能力（交付能力） 💻

Agent 最终需要以产品形式交付给用户。

* ​**后端**​：Python (FastAPI)、Node.js，能够构建高并发的 Agent API 服务。
* ​**前端（加分项）**​：React / Next.js，能够搭建 Agent 的对话界面和可视化调试面板。
* ​**部署**​：Docker、Kubernetes、Serverless（AWS Lambda / Vercel），能够将 Agent 系统部署到生产环境并实现弹性扩缩容。

### 💡 自由职业 / 求职市场定位建议

AI Agent 专家的岗位定位比"自动化工作流"更高端，客户通常是中大型企业或技术型创业公司。

**高溢价的服务方向：**

1. **企业级 AI 客服 Agent**
   * ​*方案*​：构建能够自主查询订单系统、处理退换货、升级人工客服的多轮对话 Agent，集成到网站/WhatsApp/Slack。
2. **AI 数据分析 Agent（Text-to-SQL）**
   * ​*方案*​：让业务人员用自然语言提问（如"上个月华东区销售额最高的产品是什么"），Agent 自主编写 SQL 查询数据库、生成可视化图表并撰写分析结论。
3. **AI 代码开发 Agent**
   * ​*方案*​：基于 Cursor / Devin 等范式，为企业内部搭建能够自主阅读代码库、编写代码、运行测试并提交 PR 的编程 Agent。
4. **多 Agent 研究助手**
   * ​*方案*​：为咨询公司或投资机构搭建"研究员 + 分析师 + 审核员"多 Agent 系统，自动完成行业调研、数据收集和报告撰写。
5. **Agent 安全审计与优化**
   * ​*方案*​：专门为企业已有的 Agent 系统进行"红蓝对抗"测试，找出安全漏洞和成本浪费点，提供优化方案。
