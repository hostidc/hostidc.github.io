### 阶段一：夯实底层基石（1-2个月）

*目标：满足“扎实的机器学习理论与编码能力”及“精通Python/C++”的要求。*

   * **资源**：《Pattern Recognition and Machine Learning》(PRML)、《Deep Learning》(花书) 前几章。
2. **深度学习与Transformer架构**
   * **重点**：彻底吃透 Transformer（Self-Attention, Multi-head, Positional Encoding, LayerNorm/RMSNorm）。
   * **行动**：不要只看博客，**手写一个微型 Transformer**（支持前向和反向传播）。
   * **资源**：Andrej Karpathy 的 *Let's build GPT from scratch* 视频。

### 阶段二：大模型后训练核心技术（2-3个月）⭐ 核心重点

*目标：掌握 JD 中要求的“大语言模型：预训练、微调、对齐”及“强化学习：RLHF、奖励模型”。*

1. **监督微调（SFT）与参数高效微调（PEFT）**
   * **重点**：指令微调数据构造（Instruction Tuning）、LoRA/QLoRA 原理与实现、数据混合策略（Data Mixing）。
   * **实践**：使用 `LLaMA-Factory` 或 `Axolotl` 对开源模型（如 Llama-3, Qwen-2.5）进行 SFT。
2. **人类对齐与强化学习（RLHF & Beyond）**
   * **重点**：这是后训练的灵魂。深入理解 **PPO**（Proximal Policy Optimization）在 LLM 中的应用、**Reward Model (RM)** 的训练（Bradley-Terry 模型）。
   * **前沿算法**：必须掌握 **DPO** (Direct Preference Optimization)、**IPO**、**KTO**，以及目前大火的 **GRPO** (Group Relative Policy Optimization，DeepSeek-R1 的核心)。
   * **资源**：阅读原论文 (InstructGPT, DPO, DeepSeek-R1)，复现 HuggingFace 的 `trl` 库中的 RLHF 流程。
3. **多语言与跨文化对齐**
   * **针对 JD**：研究多语言 Tokenizer 的构建（如 SentencePiece, Tiktoken），少样本学习（Few-shot），以及跨文化价值观对齐（如不同国家的文化禁忌、语言习惯）。

### 阶段三：Agent 系统与复杂推理（1-2个月）⭐ 业务核心

*目标：满足“复杂推理与通用Agent系统构建”、“任务规划、工具使用、记忆机制”。*

1. **Agent 架构与规划（Planning）**
   * **重点**：ReAct, Plan-and-Solve, Reflexion 等范式。研究模型如何进行任务拆解（Task Decomposition）和反思（Self-Correction）。
2. **工具调用（Tool Learning / Function Calling）**
   * **重点**：让 LLM 准确输出 JSON 格式的 API 调用。研究如何微调模型以提高 Tool Calling 的准确率（如 Gorilla, Toolformer）。
3. **记忆机制与 RAG**
   * **重点**：短期记忆（Context Window 管理）、长期记忆（向量数据库如 Milvus/Faiss，检索增强生成 RAG）。
4. **复杂推理能力**
   * **重点**：Chain of Thought (CoT), Tree of Thoughts (ToT)。研究如何提升模型在数学、代码和逻辑推理上的表现。

### 阶段四：多模态与端到端语音技术（1-2个月）⭐ 差异化亮点

*目标：满足“多模态能力研究”、“端到端语音技术”、“多模态内容审核”。*

3. **多模态内容审核**

   * **推荐视频**：**林轩田《机器学习基石》**（前几节数学基础部分）
   * **搜索关键词**：`林轩田 机器学习基石`

   * **推荐视频**：**斯坦福大学 Stephen Boyd《Convex Optimization》**（B站有精校中字搬运）或 **李宏毅《机器学习》中的优化部分**。
