## 一、斐讯 K2（PSG1218）硬件参数

* **CPU：MT7620A 单核 580MHz**
* 内存：64MB DDR2｜闪存：8MB SPI Flash
* 无线：2.4G 300M+5G 867M，AC1200，4 根外置天线（2 根 2.4G+2 根 5G）
* 网口：**早期版本全百兆，后期改版千兆 5 口（1WAN+4LAN）**
* 亮点：**刷机神器，万能 OpenWrt / 老毛子 / 潘多拉固件，可折腾旁路由、多拨、去广告、科学插件**
* 缺点：原厂固件停更、内存偏小、不能跑高负载宽带（300M 以上吃力）

## 二、华为 A1 硬件参数

* CPU：高通 IPQ0508 双核，性能优于 MT7620A
* 内存 128MB、闪存 128MB，全千兆 5 口
* 双频 AC1200，内置隐藏天线，机身小巧
* 亮点：**原厂稳定、HiLink 一键组网、APP 管理、家用省心，不用刷机**
* 缺点：封闭式系统，无法自由刷机改固件，拓展性极差

## 三、选购怎么选

1. ​**玩机、刷机、多拨、去广告、软路由折腾 → K2 (PSG1218)**​（二手十几元性价比之王）
2. **普通家用、稳定省心、老人用、全屋组网 → 华为 A1**
3. 宽带＞300M：两款都偏弱，优先选千兆新款路由

## 补充：K2 版本区分

K2 分​**A1/A2 版**​：A1 全百兆网口，A2 后期千兆口，买刷机优选​**A2 千兆版**​。

# 斐讯 K2 A1（PSG1218）**可以硬件扩容内存，只能换 BGA 芯片，不能加装内存插槽**

原厂：​**64MB DDR2（W9751G6KB）、单颗 BGA 焊死主板、无空焊位**​，MT7620A 芯片​**最大支持 256MB DDR2**​，主流改 128M/256M 两档。

## 一、两种扩容方案

### 1. 首选：64M→128MB（性价比最高，新手首选）

* ​**推荐颗粒**​：三星 K4T1G164QQ-HCF7、华邦 W971GG6JB、现代 H5PS1G63EFR（​**16 位 DDR2-800、1.8V、84 球 BGA**​）
* 优点：老毛子 / OpenWrt 自动识别，​**不用改 Breed 时序**​，装去广告、多拨、Docker 小插件稳稳够用
* 用途：日常主路由、多拨、去广告

### 2. 进阶：64M→256MB（极限扩容）

* ​**推荐颗粒**​：美光 MT47H128M16、海力士 H5PS2G63EMR（256MB 单片 16bit DDR2）
* 缺点：部分固件需要进​**Breed 调整 DRAM 时序**​（CL6、tRCD5），焊装难度更高
* 用途：旁路由、挂载 U 盘、跑代理、多插件常驻

> ❌ ​**不能扩 512M**​：MT7620A 内存控制器硬件上限 256MB

## 二、顺带必改：闪存扩容（8MB→16M/32M SPI Flash）

原厂 8MB 闪存太小，装插件必爆满，改内存同步换 Flash：

* 16M：W25Q128
* 32M：W25Q256
  不用编程器，焊好进 Breed 自动识别容量。

## 三、改装门槛（重点）

1. ​**工具必备**​：热风枪、助焊膏、吸锡带、防静电（BGA 拆焊，无维修经验极易吹坏主板焊盘）
2. ​**固件前提**​：​**先刷 Breed 不死引导再改硬件**​，改完进 Breed 看内存容量，再刷老毛子 / OpenWrt
3. ​**A1 天生短板**​：A1 是​**百兆网口**​，哪怕扩到 256M，宽带超 100M 依旧跑不满千兆；A2 才是千兆口

## 四、不硬改的软优化（不想焊芯片）

1. 挂载 U 盘开启​**swap 虚拟内存**​（老毛子 / OpenWrt 自带），临时缓解内存爆满，但速度慢
2. 精简固件，卸载无用插件，只保留多拨 + 去广告

## 五、选购建议

* 自己不会焊：直接买​**改好 128M+16M 闪存的二手 K2**​，比自己买芯片 + 工具划算；
* 动手玩家：优先 128M，256M 慎改。

1. ​**无 HDMI/AV 视频输出接口**​：主板没有视频编码、显示输出芯片，MT7620A 是路由 SOC，不带图像 GPU，安卓机顶盒用晶晨 S905/S912（ARM + 独显）架构完全不一样；

# 斐讯 K2 A1（PSG1218，MT7620A、64MB 内存 / 8M 闪存、百兆口、双频 1200M WiFi）全玩法

A1 标配​**64MB DDR+8MB Flash、无原生 USB、4 天线带独立功放 PA/LNA、2.4G+5G 双频**​，先刷**Breed 不死引导**是所有折腾的前提，主流固件：**Padavan 老毛子、OpenWrt、潘多拉 Pandora、石像鬼 Gargoyle**四大类。

> 硬件短板：全百兆有线口（WAN+LAN 都是 100M），有线最高跑满 100M 宽带，无线 5G 能跑满 300M 左右带宽。

## 一、基础家用玩法（Padavan 首选，最稳）

### 1. 全屋 WiFi 扩展、AP 组网

1. ​**无线中继 / 万能中继 WDS**​：蹭邻居宽带、副路由接收主路由 WiFi 再发射，老毛子中继兼容性拉满，2.4G 穿墙极强、5G 近距离高速组网；
2. ​**有线 AP**​：主路由拨号→网线接 K2 LAN 口，关闭 DHCP，纯做无线覆盖，老房子多层、阳台、车库补盲神器；
3. ​**多路由漫游（802.11r）**​：多台 K2 同 SSID、同密码，全屋无缝漫游，手机走动自动切 AP。

### 2. 精细化上网管控（家庭刚需）

* 智能 QoS 带宽限速：游戏优先、视频限速，100M 宽带多人追剧不卡顿；
* 家长管控：定时断网、黑名单网址、设备上网时段限制（小孩防沉迷）；
* 访客 WiFi：独立网段、限时限速，隔离内网设备防隐私泄露。

## 二、网络进阶折腾（OpenWrt / 老毛子）

### 1. DNS 防护 + 广告过滤（最常用）

1. 搭建​**Pi-hole（精简版）/AdGuardHome**​：全局去广告，手机、电视、平板全设备屏蔽弹窗广告、视频片头广告（A1 64M 内存只能精简部署，不能全量）；
2. DNS 加密：DoH/DoT 防运营商 DNS 劫持、域名污染。

### 2. 代理 / 异地组网

1. WireGuard/OpenVPN 客户端 / 服务端：
   * 客户端：本机上网优化；服务端：在外远程访问家里局域网设备；
2. ZeroTier 异地组网：全国各地多台 K2 组建虚拟局域网，远程 NAS、远程监控。

### 3. 多拨 / 宽带叠加（仅限多线宽带）

老毛子 / OpenWrt 支持​**单线多拨、多 WAN 口叠加​**​，多条百兆宽带带宽合并（受百兆网口限制，单口上限 100M）。

## 三、低成本冷门妙用（闲置改造）

### 1. 物联网网关（智能家居中枢）

OpenWrt 装 MQTT、HomeAssistant 精简版，做智能家居网关：联动 WiFi 插座、智能灯、摄像头，低成本全屋 IoT 中控。

### 2. 无线抓包 / 运维测试路由

* 2.4G+5G 双频网卡模式，WiFi 抓包、无线信道扫描、周边 WiFi 信号勘测；
* 小型机房测试路由、软路由备用 AP、弱电箱迷你交换机 + 无线二合一。

### 3. 监控专用 AP

工地 / 仓库摄像头无线接入点，POE 供电 + K2 做无线，远距离传输监控画面，功耗极低（整机 5W 以内）。

## 四、硬件魔改突破短板（动手党）

1. ​**飞线加装 USB 口**​：主板预留 USB 焊盘，飞线引出 USB2.0，接 U 盘 / 移动硬盘，实现：简易 NAS 离线下载、Samba 文件共享、USB 摄像头；
2. ​**内存扩容**​：64M→128MB DDR，扩容后 OpenWrt 可装更多插件，流畅跑 AdGuard；
3. ​**改 POE 供电**​：网线供电，弱电箱不用额外插座，吊顶 AP 首选。

## 五、不同固件选型建议

1. ​**小白 / 家用稳定**​：Padavan（hiboy / 老毛子），GUI 友好、无线驱动最优、信号最强，首选；
2. ​**折腾插件 / 自定义**​：Lean OpenWrt，插件多（去广告、组网、多拨）；
3. ​**带宽 QoS / 带宽优化**​：石像鬼 Gargoyle，QoS 算法顶尖，老旧宽带优化神器；
4. ​**极简稳定**​：Pandora 潘多拉，占用资源小。

## 六、避坑提醒

1. ​**百兆口硬伤**​：宽带＞100M，有线跑不满，只能无线 5G 跑高速；
2. ​**A1 64M 内存限制**​：别装太多重型插件，AdGuard+Pi-hole 二选一即可，多开容易内存溢出死机；
3. 刷机顺序：降级官方固件→刷 Breed→进 Breed 刷第三方固件，断电变砖可进 Breed 救砖。
