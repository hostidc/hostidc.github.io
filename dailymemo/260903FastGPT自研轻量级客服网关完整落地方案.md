> ⚠️ ​**微信的 5 秒超时坑**​：微信公众号要求服务器在 5 秒内响应，否则会重试。AI 调用通常需要 3-10 秒。​**解决方案**​：收到消息后先立即返回空字符串或"思考中"，然后通过微信的"客服消息接口"异步推送 AI 的回复。

2. ​**会话列表页**​：左侧显示所有待处理/进行中的会话，按时间排序，显示用户头像、昵称、最后一条消息预览、未读消息数

### ✅ 合同必须写的条款

1. ​**AI 免责**​："​*因大语言模型固有的幻觉特性，系统不承诺 AI 回复 100% 准确。甲方应定期审核知识库内容以确保准确性。*​"
2. ​**Token 费用**​："​*大模型 API 调用费用由甲方自行承担，乙方负责协助配置 API Key。*​"
3. ​**交付范围**​：明确列出支持哪些渠道（公众号/企微/网页），​**没写的渠道不算交付范围**​。
4. ​**知识产权**​："​*本项目核心网关及工作台代码知识产权归乙方所有，甲方享有永久使用权。底层 AI 引擎基于开源项目 FastGPT（Apache 2.0 协议）。*​"

### ✅ 部署必须做的事

1. ​**写死版本号**​：所有 Docker 镜像必须写死版本 Tag
2. ​**每日自动备份**​：MySQL + FastGPT 的 PostgreSQL/MongoDB，脚本化 + 定时任务
3. ​**HTTPS**​：微信/企微回调必须 HTTPS，用 Nginx + Let's Encrypt
4. ​**监控告警**​：至少配置一个服务宕机告警（如用 UptimeRobot 免费版）

### ✅ 交付后必须做的事

1. ​**教会客户自己更新知识库**​：这是客户最高频的操作，必须录一个 5 分钟的操作视频
2. ​**留一个"紧急转人工"的兜底开关**​：万一 AI 出了严重问题（如说了不当言论），客户能一键关闭 AI，所有消息直接转人工
3. ​**签维保合同**​：第二年开始收维保费（项目总额的 15-20%/年）
