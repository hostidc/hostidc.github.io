#招人

我们正在做 AI 出海产品、海外工具站和 SEO 增长项目。

这个岗位不是单纯写代码，也不是单纯做 SEO。

我们希望找到的是一名具备【独立开发者思维】的人：能够自己发现需求、判断机会、快速做出产品，并通过 SEO、用户数据和付费结果验证自己的判断。

### 你需要做什么

**1. 发现值得做的海外需求**通过 Google、Ahrefs、Semrush、Similarweb、Reddit、X、Product Hunt、竞品等渠道发现需求； 分析关键词、搜索量、竞争度、商业价值和用户痛点； 能判断一个需求到底值不值得做，而不是等别人给需求。

**2. 快速完成产品验证**围绕需求快速设计 MVP； 使用 Cursor、Claude Code、Codex 等 AI Coding 工具提高开发效率； 能独立完成或主导一个 Web 产品从想法、开发、部署到正式上线。

**3. 懂产品，也懂增长**理解 Google SEO，包括关键词、搜索意图、页面结构、Programmatic SEO、内链、外链等； 能根据 GSC、GA、用户行为数据持续优化产品； 不只是追求“网站上线”，而是关注流量、注册、转化和收入。

**4. 持续做增长实验**测试不同关键词、Landing Page、定价、功能和获客方式； 快速验证、复盘，好的项目持续投入，不好的项目及时停止； 将有效打法沉淀为可以重复使用的方法和流程。

### 我们希望你具备

有真正独立做过 Web / SaaS / AI 产品的经验； 有自己上线过的网站，而不仅仅是公司项目； 熟悉 Next.js / React / TypeScript / Node.js 等 Web 技术； 熟悉 Cloudflare、Vercel、数据库、登录、支付、API 接入等常见 SaaS 技术； 熟悉至少一种 AI Coding 工具； 对 AI 产品、独立开发、海外产品有长期兴趣； 有较强的产品 Sense 和商业意识； 英文至少可以完成资料阅读、竞品调研和海外网站开发。

### 以下经历非常加分

• 自己做过海外工具站 / AI SaaS； • 网站获得过真实 Google SEO 流量； • 有产品获得过真实注册用户或收入； • 做过从 0 到 1 的独立项目； • 熟悉 Ahrefs / Semrush / Similarweb / GSC； • 有 Product Hunt、Reddit、X、Hacker News 等海外推广经验； • 有自己的 GitHub、个人网站或独立产品作品集。

### 投递时请附上：

• 你自己做过的 1-3 个产品链接； • 这个产品的需求是怎么发现的； • 你独立负责了哪些部分； • 有没有真实流量、用户或收入； • 如果现在给你 2 周时间，你会怎么找到并验证一个新的 AI 出海产品机会。

如果你平时就在研究 AI 产品、独立开发、SEO、海外工具站，并且喜欢自己找机会、自己做产品、自己验证结果，我们会非常欢迎你。
